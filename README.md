# LearnEasyly · 學測百日錯題本

專為哲愷的 116 學年度學測設計。純 HTML/CSS/JavaScript、無後端、無付費 AI API。

## 功能
- **新增錯題**：拍照／相簿上傳、照片壓縮、在瀏覽器用 Tesseract.js 進行中英文 OCR、保留照片與可修正的題目文字。
- **自己貼上 GPT 詳解**：答案、解題步驟、理解筆記、來源、科目與單元、難度 Lv.1–5、錯誤原因。
- **本機錯題資料庫**：IndexedDB 儲存文字、圖片、紀錄；關鍵字搜尋、篩選、編輯與刪除。
- **間隔複習**：新題隔日到期；重做後按「不會／模糊／答對」安排下一次日期。連續兩次答對算作暫時掌握。
- **學測倒數**：預設 2027-01-22，設定中可改日期。
- **週進步分析**：近 8 週重做答對率、各科掌握率、錯誤原因與待加強單元。
- **每日練習**：可記錄總做題數與答對數，避免把錯題比例當成整體正確率。
- **JSON 備份／還原**：包括所有原始照片；建議每週備份。
- **PWA**：支援加到手機主畫面，快取網站基本介面。OCR 初次使用需要連網下載模型。

## 啟用 GitHub Pages

1. 在此倉庫開啟 **Settings → Pages**。
2. **Build and deployment → Source** 選擇 **GitHub Actions**。
3. 到 **Actions** 查看 **Deploy LearnEasyly to GitHub Pages**。若尚未執行，可按 **Run workflow**。
4. 部署成功後的網站網址通常是：https://easylearnfromtw.github.io/Learneasyly-/

本專案使用相對路徑，適用 GitHub Pages 子路徑網址。網域或 repo 名稱若修改，部署網址也會變更。

## 資料隱私與限制

- 題目照片、文字、詳解與日誌**不會送往 GitHub**，只存在本機的 IndexedDB。網站不內建帳號或跨裝置自動同步。
- 首次 OCR 由 CDN 下載 Tesseract 程式、WASM 與中文／英文語言模型，之後在瀏覽器辨識。數學根號、上下標、幾何圖與手寫可能失準，務必人工校對。
- 本機瀏覽器資料可能被清除或驅逐，**不能保證 100 天絕對不遺失**。重要資料請使用「設定與備份」定期匯出 JSON，存到不同設備或雲端硬碟。
- 在共用電腦開啟本網站時應注意其他使用者可能讀到本機內容。
- 使用相機需要支援拍攝選取的行動瀏覽器；若無相機選項，可改用相簿上傳。
- 難度與詳解需由使用者自行判斷／輸入。每週成長統計是基於實際重做結果，不等於學測成績預測。

## 本機預覽

在此資料夾啟動簡易靜態伺服器，例如：python -m http.server 8000

開啟 http://localhost:8000 。直接用檔案網址開啟可能受到瀏覽器安全設定影響。部署到 GitHub Pages 後使用 HTTPS。

## 技術
- 純前端：HTML、CSS、ES2020 JavaScript
- IndexedDB：錯題／複習／每日練習／設定
- OCR：Tesseract.js v5 CDN
- Service Worker：同站靜態殼層快取，優先使用網路版本
