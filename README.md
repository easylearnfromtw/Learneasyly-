# 稜角 Learn Angle

給考生用的錯題本與讀書計畫 磨出你的稜角
純 HTML CSS JavaScript 部署在 GitHub Pages 不用註冊 資料只存在自己的裝置

## 使用流程

1. 第一次打開時選好目標考試 預設學測 也可以選分科測驗 會考 統測或自訂考試
2. 用手機拍照 從相簿選擇 或直接拖曳與貼上截圖 圈選題目範圍轉成文字
3. 抄下課本 講義或老師的詳解 再用自己的話寫一次 邊寫邊自動儲存
4. 隔天開始複習 依照不會 模糊 答對安排下一次複習
5. 在讀書計畫計時 排程每天要讀的科目 記下每一段專注
6. 在落點預估輸入學測或模擬考級分 看自己在全國的位置與可能通過一階的校系
7. 在學習分析看足跡熱力圖 每週答對率 各科掌握與待補強單元

- 倒數黑板顯示距離開考還有幾天幾小時幾分 開考時刻 學測 9點20分 分科 8點40分 會考 8點30分 統測 10點20分 會考與統測依去年考程 新考程公布後更新

### 考試日期自動更新強化

## 自動更新考試日期與校系資料

- 工作流程 Update exam dates and admission data 每週一凌晨自動執行 第一次上傳這一版時也會執行一次
- 考試日期 scripts/update-exams.mjs 讀取官方公告頁面 找到新日期就更新 data/exams.json 找不到時保留已確認的官方日期與推估
- 校系資料 scripts/update-admission.mjs 從 University TW 整理 每月完整更新一次 新學年度上線時也會立刻更新 抓取時會標明身分 低頻率並遵守 robots
- 有更新時會自動提交到 data 資料夾並重新部署網站
- 想立刻更新 到 Actions 選 Update exam dates and admission data 按 Run workflow 勾選 Force a full University TW crawl
- 要手動改日期 例如颱風順延 編輯 data/exam-overrides.json 存檔推上 GitHub 後會自動套用並重新部署
- 自動更新看到不確定的日期時 會在 GitHub 開一個 考試日期需要確認 的 issue
- 目前 data/caac.json 是部分校系的示範資料 第一次自動更新完成後就會換成完整資料

## 資料保存與隱私

- 所有錯題 照片 詳解 讀書紀錄 排程與級分都存在目前裝置的 IndexedDB 不會同步到其他裝置 也不會寫入 GitHub
- 沿用原本的資料庫名稱與結構 舊錯題不需要搬移
- 無法保證資料永久保存 清除網站資料 移除應用或空間不足都可能造成遺失 請每週到設定與備份下載備份檔 備份檔現在也包含目標考試 排程與級分
- 匯入備份採合併模式 相同 ID 的資料會以備份版本覆蓋
- 第一次使用轉文字需要網路下載 Tesseract 與中英文模型 公式排版需要從 CDN 載入 KaTeX
- 詳細內容請看 privacy.html

## 進步指標定義

- 重做答對率 當週評為答對的次數除以當週全部重做次數
- 掌握 同一題連續至少兩次答對
- 高難度掌握 難度 4 與 5 的題目中達到掌握的比例
- 學習動作 新增一題或複習一題各算一次 讀書計時另外計算分鐘數
- 落點機會 每一階段都比去年通過級分多一定差距為機會高 剛好達到為有機會 差一點為挑戰

## 自動圖文辨識

上傳圖片後會自動執行裝置端 OCR 辨識 不需要切換文字 圖表 或示圖模式

- 維持 Tesseract.js 做繁體中文與英文辨識 針對數學題或低信心結果額外嘗試 PaddleOCR PP-OCRv5 神經網路模型作獨立交叉辨識 並可使用 OpenCC 轉換成臺灣繁體中文
- 會在本機嘗試辨識題目文字的位置 從剩餘非文字區域找出圖表和示圖並自動裁成獨立圖片
- 保留原始題目照片 圖表一律不猜測座標和數值 無法確認是圖表的內容會以獨立裁圖或原圖顯示
- OCR 結果直接填入可編輯的題目欄位 重新辨識不會覆蓋自行修改過的文字
- 圖像辨識是保守式啟發法 小圖 混合排版 幾何符號與手寫公式可能無法正確分離 數學題務必核對原圖
- 高畫質 OCR 擷取長邊上限提升至 3400 像素 背景流程不再反覆產生可搜尋 PDF 並保留手動下載結果的功能
- PP-OCRv5 需要首次下載較大的模型及可用瀏覽器 WASM 環境 部分手機或網路環境可能無法載入 系統會退回 Tesseract 不保證神經引擎都能運作
- 不把模型信心數字宣稱為實際正確率 不同 OCR 結果若在數字上有差異會提醒核對
- 網站仍採純前端 並不使用付費外部影像理解 API 也不能承諾 GPT 等級的視覺文字辨識

已存在的錯題 資料庫結構 備份及顯示的原裁圖不會被這次更新覆蓋

## 數學記號標示和校對

針對向量題新增明確的符號提醒與校對介面：

- 區分向量 `\\(\\overrightarrow{OA}\\)` 與線段 `\\(\\overline{OA}\\)`，不可因看到 OA 就擅自加箭頭
- OCR 出現「向量」「內積」「正射影」「投影」等線索，卻沒有辨識到上方符號時，顯示「向量或線段記號可能漏辨」
- 偵測內積點、根號、分數和上下標，於辨識校對頁、題目編輯頁和錯題詳細頁醒目提示
- 題目編輯區和 OCR 校對區提供向量、線段、內積、分數、根號快捷插入；先選 OA 或 AB 再點按，插入具正確排版的 LaTeX 記號
- 可在題目編輯區和 OCR 校對區直接預覽 KaTeX 數學式，舊題目和原始照片不會改寫
- OCR 無法可靠地從圖片還原箭頭或上劃線時只提醒校對，不自動補寫可能錯誤的符號
