隱私權政策

最後更新 2026年10月13日

不用註冊沒有帳號 沒有密碼 也不會要你的電子郵件
只存在你的裝置錯題 照片 讀書紀錄與級分都存在瀏覽器裡 不會上傳
不追蹤你沒有廣告 沒有分析工具 也不使用追蹤 Cookie

一 適用範圍

本政策適用於稜角 Learn Angle 網站與加到主畫面後的應用程式 以下簡稱本服務 本服務由個人開發者維護 原始碼公開在 GitHub

二 我們蒐集哪些資料

本服務沒有自己的伺服器資料庫 不會蒐集可以辨識你身分的個人資料 你在本服務輸入的內容只會留在你目前使用的瀏覽器裡 包含

  • 錯題的題目文字 照片 答案 詳解 單元 難度與錯誤原因
  • 複習紀錄 每日練習數量 每日打卡的狀態與目標
  • 讀書計時紀錄 讀書排程 以及你填寫的科目與備註
  • 目標考試 暱稱 每日目標 落點預估輸入的級分與志願清單
  • 外觀 特效 觸覺回饋與省電模式等偏好設定

三 資料存放在哪裡

上述資料存放在瀏覽器的 IndexedDB 與 localStorage 只有你的裝置可以讀取 我們看不到 也無法替你找回 清除網站資料 移除主畫面應用 換手機或使用無痕模式都可能讓資料消失 請定期在設定與備份匯出備份檔 備份檔只會下載到你選擇的位置

四 資料怎麼被使用

  • 在你的裝置上計算複習排程 學習統計 連續天數與成就徽章
  • 在你的裝置上比對級分與校系資料 產生落點預估
  • 文字辨識在你的瀏覽器裡執行 照片不會傳到任何伺服器
  • 我們不會販售 出租或分享你的資料 因為我們根本沒有收到你的資料

五 會連到哪些外部服務

為了讓網站正常運作 你的瀏覽器會向下列服務下載檔案 這些服務可能依照它們自己的政策記錄連線資訊 例如 IP 位址與瀏覽器版本

  • GitHub Pages 提供網站主機
  • Google Fonts 提供 Noto Sans TC Lexend 與霞鶩文楷字型
  • jsDelivr 提供文字辨識程式 Tesseract 語言資料與數學排版 KaTeX 只有在需要時才下載
  • 當你按下 University TW 等外部連結時 就會離開本服務 之後的資料處理請參考對方的政策

考試日期與校系資料是由 GitHub Actions 的自動排程從公開網站整理成檔案 再放到網站上 你的瀏覽器只會從本服務讀取這些檔案 不會直接連到資料來源

六 Cookie 與追蹤技術

本服務不使用 Cookie 不使用廣告或分析追蹤工具 localStorage 只用來記住深淺色與省電模式等設定 讓畫面在載入前就正確顯示

七 裝置權限

  • 相機與相簿 只在你按下拍照或選擇照片時使用 用來收錄題目照片
  • 剪貼簿 只在你按下複製提問模板或貼上截圖時使用
  • 震動 用於觸覺回饋 可以在設定關閉
  • 螢幕保持開啟 只在專注模式計時中使用 可以在設定關閉
  • 持久保存 由你在設定中主動申請 讓瀏覽器比較不會自動清除資料

八 未成年使用者

本服務主要給國中與高中考生使用 由於本服務不蒐集任何個人資料 也不提供社群或聊天功能 未成年人可以安心使用 若家長或監護人有任何疑問 歡迎與我們聯絡

九 你的權利

你可以隨時在本服務中查看 修改 匯出或刪除自己的資料 在設定與備份長按清除資料 就會刪除這台裝置上的所有紀錄 由於我們沒有保存你的資料 無法替你查詢或刪除其他裝置上的紀錄

十 資訊安全

本服務全程使用 HTTPS 加密連線 不過資料存放在你的裝置上 請為裝置設定螢幕鎖定 並避免在公用電腦留下紀錄

十一 政策更新與聯絡方式

本政策如有修改 會更新本頁的日期 重大變更會在網站內提示 有任何問題 歡迎到 GitHub Issues 留言

使用條款

稜角免費提供錯題整理 間隔複習 每日打卡 讀書計時 讀書排程與落點預估等學習輔助功能 本服務不需要註冊 開始使用即表示你同意本條款

二 你的責任

  • 資料只存在你的裝置 請自行定期備份 因清除資料 裝置遺失或瀏覽器限制造成的資料遺失 本服務無法復原

三 內容正確性

文字辨識結果 自動排程 考試倒數與落點預估都只是輔助 可能有錯誤或延遲 根號 上下標與圖形請以原始照片為準 重要決定請以官方公告為準

四 服務變更

我們可能為了改善體驗而調整或停止部分功能 會盡量保持舊資料可以繼續使用與匯出

五 免責

本服務依現況提供 不保證完全沒有錯誤或中斷 在法律允許的範圍內 對於使用本服務所產生的任何直接或間接損失 本服務不負賠償責任
